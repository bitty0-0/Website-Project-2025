# Website-Project-2025

# Project Overview
This project involved designing and developing a responsive movie website. The website was designed to display a selection of movies, with individual pages containing movie information and trailers.

It also included a contact page and a responsive layout to make the website accessible across different screen sizes.

# Features
  Movie showcase pages displaying a selection of films
  Movie trailers embedded within the pages
  Contact page
  Responsive website design
  CSS styling and page layouts

# Technologies Used
  HTML
  CSS
